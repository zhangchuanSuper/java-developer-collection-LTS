## 一、在IDEA中使用Maven创建项目

![image-20260818172947853](./assets/image-20260818172947853.png) 

其中Archetype(原型)的解释是：

```tex
// Archetype（原型）是一种 Maven 项目模板，它提供了一种快速启动你工作的方法。
Archetype is a Maven project template that provides a way to quickly jumpstart your work
```

在这里我们会选中

```tex
org.apache.maven.archetypes:maven-archetype-quickstart
```

然后点击创建maven项目即可。
