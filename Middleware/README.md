# JAVA开发中间件

## 一、基础介绍

JAVA开发相关中间件学习文档，JAVA开发中间件种类繁多，为了便于理解和记忆，将JAVA开发中常见的中间件按功能划分为以下几个主要类别：

- 消息队列中间件
- 分布式缓存中间件
- 分布式服务与RPC框架
- 搜索引擎中间件
- 其他辅助类中间件



## 二、使用说明

- 目录说明

  每个目录都以中间件名称作为目录名称，其中包含三个目录：Code、Document、Packages 。具体描述：

```tex
Code:用于存放该中间件基础API使用，可能包含集成其他框架(SpringBoot)的代码
Document:用于存放该中间件的相关学习文档，包括中间件的安装文档
Packages:用于存放该中间件的文件安装资源，如果Docker安装则不提供
```

## 三、中间件介绍

- 消息队列中间件（Message Queue）

  🟩 RabbitMQ：基于AMQP协议的开源消息代理，轻量级且稳定，非常适合微服务架构下的消息传递。

- 分布式缓存中间件

  🟩 Redis：支持多种数据结构（如字符串、哈希、列表等）的高性能内存缓存系统，常兼作消息代理和分布式锁。

- 分布式服务与RPC框架

  🟩 Dubbo：高性能的Java RPC框架，提供智能负载均衡、服务注册与发现机制。

- 搜索引擎中间件

  🟩 Elasticsearch：基于Lucene的分布式搜索与分析引擎，通过RESTful API交互，广泛用于日志检索和复杂数据查询。
