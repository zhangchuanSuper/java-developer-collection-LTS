MinIO 控制台是一个丰富的图形用户界面，提供与 mc 命令行工具类似的功能。

本页面提供了 MinIO 控制台的概述，并描述了配置选项和登录说明。

概述

您可以使用 MinIO 控制台执行管理任务，例如身份和访问管理、指标和日志监控或服务器配置。 要对 MinIO 进行更全面或高级的配置，请使用 mc 命令行工具。

MinIO 控制台作为 MinIO 服务器的一部分嵌入。 您还可以使用中的说明部署独立的 MinIO 控制台 github 版本仓库.

支持的浏览器

您还可以使用中的说明部署独立的 MinIO 控制台执行管理任务，例如身份和访问管理、指标和日志监控或服务器配置。

为了获得 MinIO 控制台的最佳体验，请使用您首选浏览器的最新稳定版本。 支持的一些浏览器包括：

  • Chrome

  • Edge

  • Safari

  • Firefox

  • Opera

此列表 不 详尽，可能会发生变化。

有关运行的浏览器和版本的完整列表 MinIO控制台, 详情请查看 浏览器列表 website.

小技巧

MinIO控制台 不支持 Opera迷你浏览器.

配置

MinIO 控制台继承了它的大部分配置设置 MinIO 服务器。 以下环境变量启用特定行为 MinIO 控制台：

Environment Variable

描述

MINIO_PROMETHEUS_URL

配置为从 Prometheus 服务器抓取指标的 URL MinIO 部署。 MinIO 控制台使用此服务器来填充 指标仪表板。

查看 使用Prometheus进行监控和报警 教程了解配置 Prometheus 从 MinIO 收集指标.

MINIO_BROWSER_REDIRECT_URL

MinIO 配置 外部身份管理 使用MinIO 控制台的外部可解析主机名， 用于返回身份验证响应。

当使用反向代理、负载均衡器或类似系统将 MinIO 控制台公开到公共互联网时，此变量通常是必需的。 指定解析为 MinIO 控制台的外部可访问主机名。

静态与动态端口分配

MinIO 默认情况下为每台服务器上的 MinIO 控制台选择一个随机端口 启动。 浏览器客户端访问 MinIO Server 会自动 重定向到动态选择端口上的 MinIO 控制台。 此行为模拟旧版 Web 浏览器行为，同时减少 之前 运行 MinIO 的系统上存在端口冲突的风险 嵌入式控制台更新。

您可以通过传递来选择显式静态端口 minio server --console-address 启动时的命令行选项 部署中的每个 MinIO 服务器。

例如，以下命令使用以下命令启动分布式 MinIO 部署MinIO 控制台的静态端口分配 9001 。 此次部署将响应默认 MinIO 服务器端口 :9000 上的 S3 API 操作以及 MinIO 控制台端口 :9001 上的浏览器访问。

minio server https://minio-{1...4}.example.net/mnt/drive-{1...4} \
      --console-address ":9001"

部署在需要静态端口的网络路由组件后面 路由规则可能需要设置静态 MinIO 控制台端口。 例如， 负载均衡器、反向代理或 Kubernetes 入口可能会默认阻塞 或通过动态重定向行为表现出意外的行为。

您还必须确保主机系统防火墙授予对配置的控制台端口的访问权限。

登录

在 RELEASE.2023-03-09T23-16-13Z 版本发生变更.

MinIO 控制台为未经身份验证的用户显示登录屏幕。 控制台默认提供用户名和密码提示 MinIO 管理用户.

对于配置了多个 身份管理器 的部署，, 安全令牌服务 其他身份验证方法 下拉列表以选择其他配置的身份提供程序之一。 您还可以使用使用 安全令牌服务 (STS) API 生成的凭据进行登录。

使用 MinIO 的 Play 测试环境尝试控制台

您可以使用 https://play.minio.org.cn 探索控制台。 使用以下凭据登录：:

  • 用户名: minioadmin

  • 密码: minioadmin

Play 控制台连接到 https://play.minio.org.cn 上的 MinIO Play 部署。 您还可以使用 mc 并使用 play 别名来访问此部署。
