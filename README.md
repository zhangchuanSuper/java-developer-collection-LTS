# java-developer-collection-LTS

## 一、基础介绍
Java学习记录，包括文档以及相关的代码 



## 二、使用说明
本项目分为以下几个目录

```tex
DevelopTools:开发工具目录，包括但不限于GIT、MYSQL等
Docs:开发中的相关文档等
Middleware：中间件相关目录，包括但不限于消息、缓存、搜索等相关中间件
SSM：JavaSE相关的学习文档
SpringBoot：SpringBoot框架相关的学习文档
SpringCloud：SpringCloud相关的学习文档
Template：一些模板示例
```
